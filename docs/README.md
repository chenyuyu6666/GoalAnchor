## 阅读顺序

1. 先读仓库根 [README.md](../README.md) 了解产品与安装。
2. 修改工作流或授权逻辑前，核对 CHANGELOG 与对应版本发布说明中的严格运行时边界（完整指南维护在项目文档中心，不随代码分发）。
3. 修改桌面插件前核对适配规格与验证记录（已移至项目文档中心 02/03 分类）。
4. 提交或发布前读 [开发Git提交与维护更新规范.md](开发Git提交与维护更新规范.md) 与 [CONTRIBUTING.md](../CONTRIBUTING.md)。
5. 跨会话接手时，先读 [2026-10-26 v1.0 收尾与 PR #22 合并交接](../../../Doc/04_任务记录/2026-10-26_v1.0收尾与PR22合并交接.md)；全工作区与 P0–P7 背景再查 [2026-10-20 项目开发与结构整理总交接](../../../Doc/04_任务记录/2026-10-20_项目开发与结构整理交接.md)。

## 注意

- 本目录文档会进入 sdist；修改后应检查相对链接和 `python -m build` 结果。
- 历史验证记录描述当时的环境与版本，不代表当前宿主的实时状态。
- 过程文档不要回流到本目录；统一放 `Doc\` 并在 `Doc\README.md` 登记。

# Security policy

Please do not report vulnerabilities in public Issues, Pull Requests, or discussions.

When private vulnerability reporting is available for the GitHub repository, use the repository's **Security → Advisories → Report a vulnerability** flow. Otherwise, email [chenyuyu6666@gmail.com](mailto:chenyuyu6666@gmail.com) with the subject `GoalAnchor security report`.

Include the affected version or commit, impact, and steps to reproduce. Do not include live credentials or personal data in the report. The maintainer will acknowledge reports as soon as practical; no response-time guarantee is made.

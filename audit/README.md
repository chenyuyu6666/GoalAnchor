# audit 证据目录

本目录只放**被引用 + 终态**的验收证据，随仓库分发：仓库 README、`AGENT-COMPATIBILITY.md` 与 `acceptance-map.json` 都按路径引用这里的文件，外部读者据此复核“某结论当时成立”。

## 入库规则

| 证据类型 | 位置 | 理由 |
|---|---|---|
| 终态验收结果、验收映射、JUnit 报告 | `audit/`（本目录） | 被文档按路径引用，必须随仓库分发才能核验 |
| 原始协议事件流（`*.events.jsonl`） | `Doc/03_验证与测试/<日期>_<切片>/raw/` | 可由终态摘要定位，不随仓库分发 |
| 中间探测件 | `Doc/03_验证与测试/<日期>_<切片>/probes/` | 结论已被后续更正或被终态取代 |
| 图谱生成物 | `Doc/03_验证与测试/<日期>_<切片>/graphify-slice/` | 可再生产物，不是证据本身 |

## 路径约定

- 本目录内的相对路径以**仓库根**为基准（如 `audit/zcode-protocol-final-20261025.json`）。
- 指向工作区文档中心的路径以**工作区根** `D:\Project\GoalAnchor` 为基准，形如 `Doc/03_验证与测试/2026-10-25_ZCode协议验收/raw/...`；这类路径只在工作区检出时可用。

## 引用规则

- 引用未入库的证据时必须给出它的**完整新位置**，不能只写“同名 events.jsonl”一类模糊指代。
- 原始事件流只是传输层观察，不构成 Strict 授权、审核证明或 closure 证据；结论以本目录的终态文件为准。
- 历史证据不因后续修正而改写，修正以同目录的新文件或 `Doc/04_任务记录/` 的变更记录说明。
